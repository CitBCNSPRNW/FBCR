### 📖 เกี่ยวกับระบบ
ระบบทะเบียนคุมและวิเคราะห์งบประมาณ (FBCR) พัฒนาขึ้นเพื่อใช้ในการควบคุม กำกับ ติดตามการใช้จ่ายงบประมาณเงินประจำงวด (แบบ 2221) แยกตามหมวดงบประมาณ และวิเคราะห์สถานะเงินประจำงวดเพื่อรายงานผู้บริหารและส่วนกลางอย่างมีประสิทธิภาพและโปร่งใส

- **เวอร์ชันระบบ:** `v1.1.21` (Build 2026.11.09)
- **หน่วยงานดูแล:** งานการเงินและพัสดุ ร่วมกับ ศูนย์เทคโนโลยีสารสนเทศ (CitCentre)
