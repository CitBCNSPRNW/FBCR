### 📖 เกี่ยวกับระบบ
ระบบทะเบียนคุมและวิเคราะห์งบประมาณ (FBCR) พัฒนาขึ้นเพื่อใช้ในการควบคุม กำกับ ติดตามการใช้จ่ายงบประมาณเงินประจำงวด (แบบ 2221) แยกตามหมวดงบประมาณ และวิเคราะห์สถานะเงินประจำงวดเพื่อรายงานผู้บริหารและส่วนกลางอย่างมีประสิทธิภาพ โปร่งใส และแม่นยำ

- **เวอร์ชันระบบ:** `v1.1.26` (Build 2026.11.11)
- **หน่วยงานดูแล:** งานการเงินและพัสดุ ร่วมกับ ศูนย์เทคโนโลยีสารสนเทศ (CitCentre)
